# BooksExchange: TechVerse 2026 Web Hackathon

Project from TechVerse 2026's Web Hackathon module.

## Description

This project involves developing a book exchange platform where users can swap their books with each other or receive a book from another user for points.

### Technologies Used

```txt
Frontend: React (Vite)
Backend: Firebase
Database: Firestore
```

### Instructions

Clone the repo by running: `git clone https://github.com/shaheeranser/techverse_2026_hackathon.git`. Or if you have github cli installed: `gh repo clone shaheeranser/techverse_2026_hackathon`.

Populate the firebase environment variables in the `firebase.js` file. It is prefereable you populate them using a `.env` file.
> Note: The API keys in the firebase.js file won't work as the firebase environment has been deleted.

Run `npm i` to install the packages for this application.

Run `npm run dev` to run a development environment of the application.
